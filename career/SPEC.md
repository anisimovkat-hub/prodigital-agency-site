# Навигатор digital-направлений с ИИ

Дата: 27 сентября 2026. Автор проекта: Катерина Анисимова.

## Назначение

Практический ориентир для людей без онлайн-профессии, специалистов из офлайна, работающих в найме, начинающих фрилансеров и digital-специалистов. Не психологическая диагностика, не оценка способностей, не обещание работы/дохода. Пять направлений: трафик и маркетинг, сайты, тексты/контент, визуалы, аналитика.

Результат работает автономно: без регистрации, API, платных сервисов и контактов. В каждом направлении встроены учебный бриф, копируемый промпт, порядок работы, ожидаемый результат и проверки. Для изображения нужен генератор; без него человек получает концепцию. Остальные пробы работают в обычном текстовом чате. Персональные данные, реальные бюджеты и файлы клиента не нужны.

## Предыдущие наработки

Проверены все четыре удалённые ветки и история сообщений коммитов по career/профориентация/quiz. Готовой профориентации не найдено; существующий бизнес-бриф не использован. GitHub Pages обслуживает main /root (подтверждено Settings → Pages). gh-pages содержит другой эксперимент, он не изменяется. Главная, DNS, доступы и SendPulse не изменяются.

## Итог

Сортировка по баллам. Если один лидер и следующий ниже более чем на 2 — одно направление. Если рядом ровно два варианта (разница до 2) — обе пробы. Если рядом три и больше, у лидера меньше 6 или менее 4 определённых ответов из первых восьми — честный неопределённый результат и все пять проб для самостоятельного сравнения. При ничье из пяти никакого произвольного победителя. Все ответы обязательны перед показом результата; «не знаю» разрешён.

## Мини-пробы

1. Реклама: два объявления на учебных цифрах мастерской керамики; проверка CPL/CPA, без реального запуска. Выручка не прибыль.
2. Сайты: структура и тексты пяти блоков для занятия; неизвестные контакты/расписание не выдумывать, не публиковать автоматически.
3. Контент: короткий пост из ограниченного брифа, две первые фразы, редактура вслух.
4. Визуалы: две концепции истории 9:16, промпт без встроенного текста, проверка рук/инструментов/композиции.
5. Аналитика: две недели данных, расчёты, факты отдельно от гипотез, три предложения руководителю.

Во всех пробах одна знакомая учебная предметная область уменьшает нагрузку и позволяет сравнить задачи. После пробы оценивается желание разбираться, править и повторять работу, а не только качество первого ответа ИИ.

## Исследование и решения

Изучены первичные страницы:
- Яндекс Практикум: https://practicum.yandex.ru/promo/test/ — объяснение результата и возможность сразу попробовать задачи. Заимствован принцип пути, не вопросы и не заявленная методика.
- Нетология: https://netology.ru/proftest — рабочие/бытовые кейсы, ориентир на способ решения. Заимствован принцип конкретных ситуаций, не их содержание.
- O*NET: https://www.onetcenter.org/IP.html — интересы к рабочим активностям как основа карьерного исследования; валидированная методика имеет отдельную доказательную базу. Наш продукт не называется O*NET и не претендует на такую валидность.

Собственные вопросы, тексты и дизайн. Платные материалы/промпты конкурентов не копировались.

## Интерфейс и доступность

Мобильный экран от 320px, увеличиваемый текст (нет запрета масштабирования), нативные радиокнопки/fieldset, доступ с клавиатуры, видимый фокус, возврат с сохранением выбранного, перезапуск с очисткой, копирование с запасным выделением текста, печать результата. При JS off показывается понятное сообщение. Ответы хранятся только в памяти текущей вкладки; перезагрузка сбрасывает их, сетевых запросов с ответами нет.
