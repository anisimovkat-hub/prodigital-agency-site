# Проверка содержания карьерных подсказок

4 октября 2026. Для каждой из 16 сфер есть три примера профессий с обязанностями, конкретная учебная проба, темы для изучения, поисковый запрос для видео, путь поиска вакансий и проектных задач. Сферы включают digital, работу с клиентами, организацию, образование, HR, финансы, торговлю и технические роли. Указаны ограничения более сложных профессий: разработка, бухгалтерия, перевод и преподавание требуют отдельной подготовки.

Каталог и тексты — авторская редакционная группировка. Профили интересов сравниваются с данными по похожим профессиям O*NET 31.0, но сами русские вопросы, соответствие сфер, весовые коэффициенты и маршруты не валидированы. При низкой определённости предложено сравнить несколько сфер и выполнить две маленькие пробы; специалист не назначается случайным образом.
