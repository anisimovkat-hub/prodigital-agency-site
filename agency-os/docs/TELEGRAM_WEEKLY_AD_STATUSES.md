# Еженедельные статусы рекламы в Telegram

Каждый активный сценарий из `telegram_weekly_status_scenarios` запускается Vercel
cron по понедельникам в 10:00 `Europe/Moscow` (`0 7 * * 1` UTC). Он берёт только
предыдущую полную неделю — с понедельника по воскресенье — и формирует один пост
на проект. Бот не обращается к рекламному кабинету: источником служат
нормализованные строки Agency OS.

## Где настраивать новый статус

1. В `telegram_weekly_status_scenarios` добавить проект, канал, ID чата получателя,
   расписание, ссылку на отчёт, шаблон `project_weekly_ad_status` и флаг активности.
2. В `telegram_weekly_status_directions` добавить направления сценария: название,
   канал и один проверенный счётчик Метрики. Направление можно связать с
   `project_ad_directions`, но отчёт всё равно проверяет счётчик у каждой кампании.
3. В `telegram_weekly_status_goals` добавить GoalID, бизнес-ярлык, вид цели и,
   при необходимости, подпись ценности. Для AI-лендингов отметить три обращения
   `include_in_contact_cpa = true`.

Цели одинакового смысла из разных счётчиков остаются разными строками. Результаты
агрегируются только внутри ключа `project_id + direction_id + counter_id + goal_id + date`.

## Данные и защита от ложных цифр

- Расход попадает в статус только из строк `spend_includes_vat = true`.
- Цель с отсутствующим или неполным измерением выводится как `нет данных`, а причина
  сохраняется в `telegram_weekly_status_deliveries.last_error` и журнале cron.
- CPA не считается при нуле конверсий: цель получает `0 / —`.
- Ценность цели выводится только из её собственного `Revenue_<goal_id>_LC`. Для
  покупки без покупок показывается `0 ₽`; отсутствующая ценность — `—`.
- Резервный лист можно описать в `fallback_source` сценария и `fallback_match`
  направления, но он не заменяет нормализацию и не может смешивать разные счётчики.

## Kolvika

Сценарий Kolvika создаётся только после точной привязки чата Софы. Направления:
`14496817` (Gems4U), `71291494` (Kolvika Center), `112938684` (AI-лендинги).
Покупка Kolvika Center не добавляется до появления подтверждённого GoalID.
