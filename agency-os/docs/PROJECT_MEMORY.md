  Проверка ALMA: охват 31,6 тыс., рост +15, ER 0,37%, 7 публикаций; таблица показывает reach,
  views, реакции, сохранения и репосты. У нескольких микропрофилей Meta не отдаёт историю

- Локальные проверки: TypeScript, ESLint, 129 unit-тестов и production build зелёные.
