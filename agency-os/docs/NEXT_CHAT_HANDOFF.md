Основная Meta-статистика загружается ежедневно Vercel Cron. Главный дашборд не показывает
падение показов и техническую несвежесть; тревога CPA возникает только при одновременном
снижении количества заявок. Самостоятельное восстановление пароля работает через Supabase Auth.
Период отчёта и ручной загрузки Meta выбирается одной кнопкой-календарём в шапке `/analytics`.
Выпадающее окно содержит готовые интервалы, два месяца календаря и «Обновить»; отдельные

даты недоступны. Ручная догрузка Meta спрятана в «Обновить данные Meta» и видна только при
связанном кабинете; технический блок Яндекс.Директа из отчёта убран. Загрузка получает
статистику только на чтение.

Стартовый экран `/analytics` больше не выводит сводные показатели по всем проектам. По
умолчанию он показывает последние 7 дней отдельными компактными карточками активных проектов:
главную цену лида/цели, расход и результаты. Сверху доступны период, переход к проекту и
поиск; сравнение берёт предыдущий интервал той же длины. Денежные значения и цена цели
появляются только при одной валюте и сопоставимой цели; иначе карточка прямо сообщает об
ограничении. `0035_project_color.sql` добавила настраиваемый цвет проекта в production.
