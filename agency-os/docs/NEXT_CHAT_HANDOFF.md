## Короткий статус

Production-MVP работает на `https://prodigital-os.vercel.app` из ветки
`claude/agency-ops-mvp-design-ykrrn0`, Root Directory — `agency-os/`. Прикладные миграции
применены до `0032`. Работают проекты, клиенты, сотрудники и RLS, задачи/канбан/повторы,
два Google Calendar без дублей и приёмов пищи, учёт времени задач, медиапланы,
единая аналитика Meta + Instagram и публичные клиентские отчёты.

Основная Meta-статистика загружается ежедневно Vercel Cron. Главный дашборд не показывает
падение показов и техническую несвежесть; тревога CPA возникает только при одновременном
снижении количества заявок. Самостоятельное восстановление пароля работает через Supabase Auth.
Оба ручных Meta-импорта теперь поддерживают быстрые периоды 3, 7 и 14 дней наряду с 30, 90,
180 и 365 днями; они получают статистику только на чтение.

## Правила безопасности и качества

- Meta/Яндекс/ИИ-токены — только sensitive env Vercel, никогда в Git, Supabase или логах.
- Интеграции рекламы — read-only. Не менять кампании, ставки и бюджеты.
- RLS не ослаблять; `src/lib/supabase/types.ts` обновлять вручную при каждой миграции.
- Не суммировать разные валюты; цель конверсии всегда указывать явно.
- Графики — лёгкий SVG, не добавлять `recharts`.
- Перед каждым push: `tsc --noEmit`, ESLint, Vitest и production build.
- Коммитить только собственные файлы; не использовать `git add -A` в общем репозитории.
- После изменения поведения обновлять `CLAUDE.md`, `PROJECT_STATUS.md`, `PROJECT_MEMORY.md`,
  `DECISIONS.md` и профильный документ аналитики.
