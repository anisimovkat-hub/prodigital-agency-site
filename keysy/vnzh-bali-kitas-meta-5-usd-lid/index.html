ВНЖ на Бали для иностранцев

KITAS на Бали для иностранцев: 147 лидов по 5,28 $ за период с декабря 2023 по январь 2024.

рекламная платформаMeta* / Instagram*
цель кампанииЛидогенерация
цена результата5,28 $ / лид
Релокация, ВНЖ и визыБали и ИндонезияТаргетированная реклама

Задача

Таргетированная реклама на услугу получения ВНЖ на Бали для иностранцев (KITAS). Кампания велась с декабря 2023 по январь 2024, задача — получать качественные обращения по узкой международной аудитории.

Что сделали

  1. Сегментация аудитории по гео и поведенческим признакам
  2. Разработка креативов с упором на конкретные боли эмигрантов
  3. A/B-тестирование офферов и форматов
  4. Оптимизация по качеству лидов совместно с заказчиком

Результат

147 лидов по 5,28 $ — хороший результат для международной ниши с узкой аудиторией.
