Задача

Масштабная кампания по лидогенерации для юридической компании в нише ВНЖ и релокации в Португалию. Период работы по данным портфолио — июль–ноябрь 2023.

Что сделали

  1. Разработан контент-план с несколькими креативными концепциями
  2. Запущены look-alike аудитории на основе клиентской базы
  3. Масштабирование на работающих связках
  4. Постоянная ротация крео для борьбы с выгоранием

Результат

2 122 лида по 2,14 $ — один из лучших результатов в нише иммиграции. Кампания масштабировалась без потери качества лидов.
