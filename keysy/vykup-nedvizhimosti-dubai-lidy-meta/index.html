Агентство по выкупу недвижимости в Дубае

Лидогенерация на сайт для агентства по выкупу недвижимости в Дубае: CPL по проекту держится в диапазоне 70–90 AED. В срезе 2026 — 648 кликов на сайт по 11,57 AED.

Задача

Таргетированная реклама для агентства по выкупу недвижимости в Дубае в 2024–2026 годах. Задача — приводить целевые лиды на сайт от собственников, инвесторов и покупателей с высоким чеком.

Что сделали

  1. Сегментация по географии, интересам и сценариям владения недвижимостью
  2. Креативы с понятным оффером для собственников недвижимости в Дубае
  3. Трафик вёлся на сайтовую воронку с формой заявки и отдельными сценариями в WhatsApp
  4. Оптимизация велась по стоимости и качеству заявок

Результат

CPL по проекту удерживался в диапазоне 70–90 AED. В свежем срезе 2026 года рекламные кампании дали 648 кликов на сайт при расходе 7 498 AED и среднем CPC 11,57 AED; дальше результат оценивается по качеству заявок, а не только по объёму трафика.
