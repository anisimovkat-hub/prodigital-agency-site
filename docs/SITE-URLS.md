Старый адрес https://anisimovkat-hub.github.io/prodigital-agency-site/ сохраняется для совместимости. Скрипт переводит посетителя на новый адрес с тем же путём, параметрами и якорем. Это переход в браузере, не серверный HTTP 301. При отключённом JavaScript остаётся полная старая страница с canonical на новый адрес.

Корень https://anisimovkat-hub.github.io/ не является сайтом агентства и возвращает 404. Адрес /prodigital-agency/ в старом аккаунте также не создан. Домен .com не покупался.

Папки /uslugi/, /nishi/, /strany/ самостоятельных страниц пока не имеют — используйте существующие вложенные страницы из списка.
